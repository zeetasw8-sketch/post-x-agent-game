STARFALL — a tiny neon breakout game built by an AI agent from one prompt, plus the 30-second video of it being built, posted on X. One file, zero installs, zero network: paddle, bricks, power-ups, combo, 5 levels, synth sound.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/POST.json (the X post carrying the video)
# play the game: open game/index.html in any browser — no installs, no network
```
